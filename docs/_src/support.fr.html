Comment jouer ?

Les nombres à côté de chaque ligne et au-dessus de chaque colonne t’indiquent combien de cases sont remplies, dans l’ordre. Remplis les cases avec le pinceau et marque les cases vides d’un X. Commence par le tutoriel : il t’apprend chaque technique pas à pas. Tu bloques ? Touche le petit chat sous la grille pour obtenir un indice.

Comment obtenir une carte de race ?

Résous toutes les grilles d’une race. La carte est ajoutée à ta collection ; touche une carte pour la retourner et en savoir plus sur la race.

Comment jouer au Puzzle Chat ?

Placez un chat dans chaque couleur, chaque ligne et chaque colonne ; deux chats ne peuvent jamais se toucher, même en diagonale. Touchez une case pour la marquer d'un X, touchez deux fois pour placer un chat. En mode facile, les cases autour de chaque chat trouvé sont barrées pour vous. Le niveau 1 est un court tutoriel.

Catgrid Premium

Premium supprime les publicités et débloque 9 grilles dorées pour chaque race ; résous-les pour gagner la Carte dorée de la race. Va dans Réglages → Premium. Pour résilier, ouvre dans iOS Réglages → ton nom → Abonnements. Si tu as changé d’appareil, touche Restaurer les achats.
