Como eu jogo?

Os números ao lado de cada linha e acima de cada coluna indicam quantos quadrados preenchidos existem, em ordem. Preencha os quadrados com o pincel e marque os vazios com X. Comece pelo tutorial; ele ensina todas as técnicas passo a passo. Travou? Toque no gatinho embaixo do tabuleiro para ver uma dica.

Como consigo a carta de uma raça?

Resolva todos os quebra-cabeças de uma raça. A carta é adicionada à sua coleção; toque em uma carta para virá-la e ler sobre a raça.

Como jogar o Quebra-Gato?

Coloque um gato em cada cor, cada linha e cada coluna; dois gatos nunca podem se tocar, nem na diagonal. Toque numa casa para marcá-la com X e toque duas vezes para colocar um gato. No modo fácil, as casas ao redor de cada gato encontrado são marcadas para você. A fase 1 é um tutorial curto.

Catgrid Premium

O Premium remove os anúncios e desbloqueia 9 quebra-cabeças dourados para cada raça; resolva-os para ganhar a Carta Dourada da raça. Vá em Ajustes → Premium. Para cancelar, abra no iOS Ajustes → seu nome → Assinaturas. Se você trocou de dispositivo, toque em Restaurar compras.
