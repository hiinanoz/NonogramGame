遊び方は？

各行の横と各列の上にある数字は、塗りつぶすマスがいくつ連続しているかを順番に示しています。ブラシでマスを塗りつぶし、空白のマスには×を付けましょう。まずはチュートリアルから始めてください。すべてのテクニックを一歩ずつ教えてくれます。行き詰まったら、盤面の下にいる小さな猫をタップするとヒントがもらえます。

猫種カードはどうやって手に入れるの？

ひとつの猫種のパズルをすべて解きましょう。カードがコレクションに追加されます。カードをタップすると裏返して、その猫種について読むことができます。

ねこパズルの遊び方は？

すべての色・行・列に猫を1匹ずつ置きます。猫どうしは斜めでも隣り合えません。マスを1回タップで×、2回タップで猫を置きます。かんたんモードでは、見つけた猫のまわりに自動で×が付きます。ステージ1は短いチュートリアルです。

Catgrid Premium

Premiumでは広告が非表示になり、すべての猫種で9つのゴールデンパズルが解放されます。それらを解くと、その猫種のゴールデンカードがもらえます。設定 → Premiumからどうぞ。解約するには、iOSの設定 → ユーザ名 → サブスクリプションを開いてください。デバイスを変更した場合は、購入を復元をタップしてください。
