ゲームのデータはお使いのデバイス内にとどまります。Catgridにはアカウントも独自のサーバーもありません。解いたパズル、ベストタイム、集めたカード、保存したゲーム、設定はすべてお使いのデバイスにのみ保存され、アプリを削除すると消去されます。

広告

CatgridはGoogle AdMobを通じて広告を表示します。広告の表示と効果測定のため、Googleは広告識別子（トラッキングを許可した場合のみ）、IPアドレス、デバイスのモデル、広告とのやり取りに関するデータなどのデバイス情報を収集することがあります。必要とされる地域（EEAや英国など）では、パーソナライズ広告が表示される前に同意を求められます。選択内容は設定 → 広告のプライバシー設定でいつでも変更できます。また、iOSの設定 → プライバシーとセキュリティ → トラッキングでトラッキングを許可または拒否することもできます。Googleのサービスを使用するアプリから収集した情報のGoogleによる使用もご覧ください。

購入

Catgrid Premiumのサブスクリプションの処理はすべてAppleが行います。私たちがお支払い情報を目にすることはありません。サブスクリプションの管理や解約は、Apple IDの設定から行えます。

Game Centerと共有

Game Centerにサインインしている場合、Game Centerのニックネームとスコア（デイリー連続記録、解いたパズル数、ねこパズルのステージ数）がAppleのランキングに送信され、Appleのプライバシーポリシーに従って処理されます。iOSの設定 → Game Centerからサインアウトできます。解いたパズルやカードを共有すると、画像は端末内で作成され、選んだアプリにのみ送られます。私たちには何も届きません。

お子さまについて

Catgridは13歳未満のお子さまを対象としておらず、お子さまの個人情報を故意に収集することはありません。

第三者サービス

Catgridは以下のサービスを利用しています。これらのサービスは、本ポリシーと同等以上の保護を提供する各社のプライバシーポリシーに基づいてデータを処理します：

ゲームデータは、リセットするかアプリを削除するまでお使いのデバイスに残ります。Googleは独自の保存ルールに従って広告データを保持します。

お客様の権利（EEA、英国、米国の州）

パーソナライズ広告はお客様の同意がある場合にのみ表示され、その同意は設定 → 広告のプライバシー設定でいつでも撤回できます。パーソナライズされていない広告は、広告の配信と不正防止におけるGoogleの正当な利益に基づいています。お客様には、ご自身のデータへのアクセス、訂正、削除を求める権利、データの処理に異議を唱える権利、そして居住地のデータ保護機関に苦情を申し立てる権利があります。プライバシー法のある米国の州にお住まいの方は、パーソナライズ広告が表示される場合、同じメニューからオプトアウトできます。私たちはお客様の個人データを自ら保持していないため、広告データに関するご請求にはGoogleが対応します。私たちにご連絡いただければ、お手伝いします。

お客様の選択

設定 → 進行状況をリセット、またはアプリの削除によって、ゲームの進行状況をいつでもすべて削除できます。サーバーにはデータを一切保存していないため、私たちの側で削除すべきものはほかにありません。Googleが広告のために収集したデータについては、設定 → 広告のプライバシー設定（利用可能な場合）またはiOSのトラッキング設定をご利用ください。
